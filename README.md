# POO-Programacao-Orientada-a-Objeto-exemplos-em-PHP
Explorando a Programação Orientada a Objetos (POO) com PHP. Este repositório contém exemplos práticos e didáticos para aprender e reforçar os conceitos fundamentais de POO, como classes, objetos, herança, encapsulamento, polimorfismo e interfaces, utilizando a linguagem PHP.
